# Rana

Rana pixel-art animada sobre una pantalla en blanco, usando el spritesheet `assets/frog_sheet.png`
(fondo hecho transparente a partir de `assets/frog_sheet_original.jpg`).

Abre `index.html` en el navegador.

- La rana descansa (respira, parpadea, hincha la garganta), se gira, da saltitos y saltos largos.
- Aparecen moscas cada pocos segundos; la rana se acerca a saltos y las caza con la lengua.
- Haz clic en la pantalla para soltar una mosca.
